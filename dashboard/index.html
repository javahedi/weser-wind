Under the hood

A production-style stack, fully containerised

This demo runs on a real pipeline: the same architecture a wind operator would use, scaled down to one server.

01 · INGEST
Sensor simulator

Physics-based wind (Weibull + turbulence) and power curve. Rust / Python

02 · TRANSPORT
MQTT broker

Industry-standard IoT messaging. Mosquitto

03 · PROCESS
Clean & aggregate

Validation, outlier removal, 10-min means. Python · FastAPI

04 · STORE
Time-series DB

Hypertables and continuous aggregates. TimescaleDB

05 · ANALYSE
Anomaly detection

Power-curve residuals and thermal limits. NumPy · scikit-learn

06 · SERVE
Live dashboard

WebSocket stream, deployed with CI/CD. Docker · Caddy · Hetzner

Demo by DoppleJa · Bremen. All data is simulated; Weser Wind Park is fictional.
